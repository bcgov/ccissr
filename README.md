Repository for storing and tracking changes to information tables that serve as CCISS model data inputs and standalone data products. Up to date tables are stored as CSVs in the tables folder (suitability.csv, edatopic.csv, WNA_BGCs.csv, site_series.csv) with versions listed in the tables README. Previous table versions and are stored in the versioned folder with detailed track changes in the track changes subfolder. Descriptions of each table in the tables folder.
