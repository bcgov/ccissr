This branch is a repository for storing and tracking changes to information tables that serve as CCISS data inputs and standalone data products including the CCISS Environmental Suitability ratings, Western North America (WNA) Edatopic Space Table, WNA Site Series Information Table, and the WNA Biogeoclimatic Units Attribute Table. 

Up to date tables are stored as CSVs in the 'tables' folder. Previous table versions and are stored in the 'versioned' folder with detailed track changes in the 'track changes' subfolder. For additional information on each of these datasets please go to https://catalogue.data.gov.bc.ca/dataset/cciss-environmental-suitability-ratings and https://catalogue.data.gov.bc.ca/dataset/cciss-western-north-america-bec-tables
